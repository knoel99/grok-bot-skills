# skills-grok

This repository hosts skills in the Cursor and Anthropic format: one folder per skill, a `SKILL.md` with `name` and `description`, and the code in `scripts/`.

- grok-status — follow a Grok Build streaming-json log and write status files while a headless grok run is in progress.
  - Folder: https://github.com/knoel99/skills-grok/tree/main/skills/grok-status
  - Script: https://raw.githubusercontent.com/knoel99/skills-grok/main/skills/grok-status/scripts/grok-status.py
- dialogue-turns — parse and validate multi-bot dialogue turns, and keep private thoughts out of the shared transcript.
  - Folder: https://github.com/knoel99/skills-grok/tree/main/skills/dialogue-turns
  - Script: https://raw.githubusercontent.com/knoel99/skills-grok/main/skills/dialogue-turns/scripts/dialogue_turns.py

Download a script only after a yes.
